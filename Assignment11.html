Assignment 11 - BSIT Quick Class Advisor

This interactive class advisor is based on the Daytona State College Bachelor of Science in Information Technology (BSIT) 2026-2027 degree planner. Select the classes you have already completed, review the courses that become available, and build a draft schedule across the next six terms.

The advisor checks prerequisites, supports AND/OR prerequisite rules, displays course notes, tracks credit hours, and creates a printable schedule. Course information is stored in JSON and the course cards and schedule controls are created dynamically with JavaScript.

Advising note: This is a planning aid and not an official degree audit. Always confirm current course availability, transfer equivalencies, catalog requirements, and your final schedule with a DSC academic advisor. The workbook identifies the BSIT catalog year as 2026-2027. The workbook's Planner tab says to select two specialization courses (6 credits), while its Requirement tab describes one course (3 credits) and labels the requirement total differently. This page keeps the specialization choices visible; confirm the correct graduation requirement with an advisor.

Courses and Prerequisites

Check the box beside a course if you have already completed it. To plan a course, choose a term from its dropdown. A course can only be scheduled when its prerequisite rules are satisfied before that term and it is listed as offered in that season. Courses already completed are excluded from the schedule.

Project Modifications

  • Used the 2026-2027 BSIT degree planner and requirement worksheet from the supplied 2027 Degree Planner workbook.
  • Represented courses, credit hours, categories, terms offered, prerequisite rules, and course notes as JSON data.
  • Built course cards, completed-course checkboxes, term selectors, and the schedule table dynamically with JavaScript.
  • Added prerequisite checking with AND groups and OR alternatives. For example, Data Structures requires one programming course AND one discrete-math course.
  • Added notes explaining course choices and alternatives, including the requirement to select one course from each applicable option group.
  • Added part-time and full-time draft planning, credit-hour totals, schedule clearing, and a print-friendly schedule.
